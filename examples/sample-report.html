high

Uncaught JavaScript error on a page with a form

"Cannot read properties of undefined (reading 'start')". A script crash can stop the form from submitting.

Fix: Open the page, check the browser console, and fix or remove the failing script. Re-test the form afterwards.

high

WhatsApp button points to a number that cannot work

https://wa.me/+0123abc?text=Hello (non-numeric). WhatsApp expects digits only, with the country code and no leading zeros.

Fix: Use https://wa.me/<countrycode><number> with digits only, for example https://wa.me/14155552671.

medium

Tidio chat widget is installed but never appears

The Tidio script is on the page but no chat bubble or frame was found in the page after it loaded. It may be off by schedule, hidden by consent settings, or misconfigured.

Fix: Open the page on a phone and look for the Tidio bubble. If it is missing, check the widget ID, domain allow-list and business-hours settings in Tidio.
